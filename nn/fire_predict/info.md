# Referencia del Artículo del Dataset

Este proyecto utiliza el dataset **TS-SatFire** para la predicción de la progresión de incendios forestales.

### **Detalles del Artículo**
*   **Título:** TS-SatFire: A Multi-Task Satellite Image Time-Series Dataset for Wildfire Detection and Prediction
*   **Autores:** Yu Zhao, Sebastian Gerard, Yifang Ban
*   **Año:** 2024
*   **Link:** [https://arxiv.org/abs/2412.11555](https://arxiv.org/abs/2412.11555)
*   **DOI:** [10.48550/arXiv.2412.11555](https://doi.org/10.48550/arXiv.2412.11555)
